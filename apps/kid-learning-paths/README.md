# Kid Learning Paths

A single-page demo of the **Marble Skill Taxonomy** — an open prerequisite
graph of 1,616 primary-school concepts linked by 3,317 dependency edges. Pick
a child's age and a target concept, then:

1. **Prerequisite tree** — every concept that leads to the goal, each link
   annotated with *why* it's required (soft links behind a toggle), plus an
   ordered **learn-first path** (topological order, earliest ages first).
2. **Placement check** — built from each topic's `assessmentPrompt` and
   `evidence`. Starts at the goal and works backward: "Yes" assumes the
   concept and its prerequisites are mastered, "Not yet" walks down to its
   hard prerequisites. Capped at 12 questions.
3. **Gap report** — mastered / missing / untested lists plus a **learn-next**
   list (gaps whose prerequisites are all mastered).
4. **AI practice** — 3 questions + 1 hands-on activity per gap, generated by
   **gpt-oss-120b** on a US-hosted provider, or canned output in mock mode.

Two one-click sample profiles — **Kindergartner (Charlie)** (age 5, adding and
subtracting) and **5th grader (Lillian)** (age 10, adding fractions with
unlike denominators) — pre-fill the whole flow with clearly fake answers
labeled "Sample data".

## Run it

```bash
cd apps/kid-learning-paths
bun install
bun run dev
```

Open http://localhost:3000. **No API keys are needed** — with no keys set (or
with `MOCK_PROVIDERS=1`), practice generation returns canned output.

## Environment variables

Copy `.env.example` to `.env.local` if you want real AI practice. The first
key set (in this order) picks the provider; all serve OpenAI's open-weight
gpt-oss-120b via the OpenAI-compatible `openai` SDK:

| Variable            | Provider     | Model id                                 |
| ------------------- | ------------ | ---------------------------------------- |
| `TOGETHER_API_KEY`  | Together AI  | `openai/gpt-oss-120b`                    |
| `FIREWORKS_API_KEY` | Fireworks AI | `accounts/fireworks/models/gpt-oss-120b` |
| `BASETEN_API_KEY`   | Baseten      | `openai/gpt-oss-120b`                    |
| `MOCK_PROVIDERS`    | —            | `1` forces canned output                 |

US-hosted providers and a US open-weight model only.
